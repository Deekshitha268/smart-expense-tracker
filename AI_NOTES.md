# AI Usage Notes

## AI Tool Used

-> ChatGPT

## 1. Which parts were AI-assisted vs. Written by me

I created the Smart Expense Tracker API in Python using Flask.

I used ChatGPT to look at the project structure talk about ways to build the REST API and get ideas to make the code better in terms of how it's organized how it checks for errors and how it handles problems.

The way the program works the Flask routes, how everything connects, testing, fixing problems building the frontend and making sure the project is put together properly were all done by me.

## 2. What I validated, tested or changed

Before I used any ideas that came from AI I checked them. Made sure they were correct.

I:

-> Built and tested each API endpoint.

-> Made sure the JSON file read and write operations worked.

-> Added checks to make sure required fields are present and expense amounts are positive.

-> Tested filtering expenses, calculating totals and removing entries.

-> Made changes to the code to make it easier to read and make sure the solution followed the assignment rules.

-> Ran the test suite to check that the API works properly.

## 3. AI suggestions I decided not to use

I decided not to use some of the ideas from AI such as:

-> Using a database like SQLite or PostgreSQL because the assignment says that JSON or in-memory storage is enough.

-> Adding login and user accounts because that was not part of what was asked for in the assignment.

-> Adding features than what was needed to keep the solution simple and match what the assignment asked for.

## Reflection

AI was used as a helper to look at ideas for how to build the project and suggest ways to make it better. All the ideas, from AI were checked before being used. The final version of the project was made, tested and improved by me.
